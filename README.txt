OPENING
1. Extract this ZIP completely.
2. Copy your original media files into the matching assets folders (see below).
3. Open index.html in Chrome/Edge. For YouTube embeds, a local web server or hosted website is more reliable than opening file:// directly.

ADDING IMAGES
Because a browser cannot automatically enumerate arbitrary files in a local folder, add new image paths to the matching arrays in js/data.js. Use supported common formats such as .jpg, .jpeg, .png or .webp, and keep filenames simple. Challenge carousels are set to 3 seconds; film-page stills to 4 seconds; homepage stills to 5 seconds. The home hero displays up to four preview images at a time and provides vertical pagination when there are more than four.

GOOGLE DRIVE
The Loop short-film player uses a Google Drive /preview embed and includes a direct-watch fallback. Set file sharing to “Anyone with the link — Viewer” for public viewing.
